Politique de confidentialité

Comment nous traitons vos données. Spoiler : on ne collecte presque rien.

Dernière mise à jour : septembre 2026

1. Responsable du traitement

Le responsable du traitement des données collectées sur le site teamlauncher.vercel.app est :

  • Nom : Team Star Wars
  • Contact : teamluncher@gmail.com

Team Group est un projet personnel. Il n'y a pas de structure juridique derrière, juste un dev qui bosse.

2. Données collectées

Le site est statique. Il n'y a pas de base de données, pas de compte utilisateur, pas de tracking.

Formulaire de contact : votre pseudo et votre message sont envoyés directement par e-mail via votre client mail. Aucune donnée n'est stockée sur nos serveurs.

Journaux serveur : Vercel peut conserver temporairement des logs techniques (adresse IP, navigateur, horodatage) pour le fonctionnement du site. Ces données sont automatiquement purgées.

Aucune donnée n'est collectée à des fins de profilage, de marketing ou de revente.

3. Finalités du traitement

Les seules finalités sont :

  • Répondre à vos messages via le formulaire de contact
  • Assurer le fonctionnement technique du site (logs Vercel)

Il n'y a pas de newsletter, pas d'abonnement, pas de profil utilisateur, pas de publicité.

4. Base légale du traitement

  • Formulaire de contact : intérêt légitime (répondre à une demande entrante)
  • Logs serveur : intérêt légitime (sécurité et fonctionnement du site)

5. Durée de conservation

  • Messages de contact : conservés le temps nécessaire au traitement, puis supprimés
  • Logs Vercel : purgés automatiquement après quelques jours

Il n'y a pas de base de données persistante. Quand le message est traité, il est supprimé.

6. Destinataires des données

Les données sont traitées exclusivement par Team Star Wars.

  • Hébergeur : Vercel Inc. — Politique de confidentialité Vercel
  • E-mail : Gmail (pour la réception des messages du formulaire)

Aucune donnée n'est transmise à des tiers à des fins commerciales ou publicitaires.

7. Cookies

Le site n'utilise aucun cookie. Pas de tracking, pas d'analytics, pas de publicité.

Vercel peut déposer un cookie technique strictement nécessaire au fonctionnement du CDN. Ce cookie ne nécessite pas de consentement.

8. Vos droits

Conformément au RGPD, vous disposez des droits suivants :

  • Droit d'accès : obtenir une copie de vos données
  • Droit de rectification : corriger des données inexactes
  • Droit à l'effacement : demander la suppression de vos données
  • Droit à la portabilité : recevoir vos données dans un format structuré
  • Droit d'opposition : vous opposer au traitement de vos données

Pour exercer ces droits, contactez-nous à : teamluncher@gmail.com

En cas de réponse insatisfaisante, vous pouvez introduire une réclamation auprès de la CNIL.

9. Sécurité

Les communications sont chiffrées via HTTPS. Le site est hébergé sur Vercel, une plateforme sécurisée avec certificat SSL automatique.

Aucun mot de passe, aucune donnée bancaire, aucune information sensible n'est stockée sur nos systèmes.

10. Mise à jour

Cette politique peut évoluer pour refléter les services ou la réglementation. La date de mise à jour en haut de page permet d'identifier le texte applicable.
