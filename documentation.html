Documentation Team Group

Tout ce qu'il faut savoir pour utiliser Team Launcher, Aqua Launcher et contribuer au projet.

Dernière mise à jour : septembre 2026

Qu'est-ce que Team Group ?

Team Group est une entreprise spécialisée en cybersécurité et solutions gaming natives Windows. Fondée par Team Star Wars, elle développe des outils performants, sécurisés et transparents.

Nos solutions actuelles :

  • Team Shield — Outil de cybersécurité natif Windows (en développement)
  • Team Launcher — Launcher Minecraft en C# natif Windows
  • Aqua Launcher — Launcher multigaming (en cours de dev)
Team Launcher est gratuit, open source, et tourne sur ~65 Mo. Pas d'Electron, pas de Chromium. Le site officiel : teamlauncher.vercel.app

Team Shield — Cybersécurité

Team Shield est notre outil de cybersécurité natif Windows. Protection en temps réel, analyse de menaces et firewall avancé.

1 Fonctionnalités principales

  • Protection en temps réel — Surveillance continue du système
  • Analyse de menaces — Détection avancée des logiciels malveillants
  • Firewall avancé — Contrôle granulaire du trafic réseau
  • Performance native — Développé en C# pour Windows

2 État de développement

Team Shield est actuellement en cours de développement. Pas de date de sortie annoncée. Suivez l'avancement sur le site officiel ou via le GitHub.

Team Launcher — Installation et utilisation

1 Télécharger le launcher

Rendez-vous sur le site officiel ou sur GitHub pour télécharger la dernière version :

  • Site officiel
  • GitHub (code source + releases)

Le launcher est un fichier .exe d'environ 65 Mo. Pas besoin d'installer quoi que ce soit d'autre.

Windows uniquement. Team Launcher est développé en C# / WinForms pour Windows 10/11. Pas de version Mac ou Linux pour l'instant.

2 Lancer le launcher

Double-cliquez sur le fichier téléchargé. Pas d'installation requise, c'est un .exe portable.

  • Si Windows Defender affiche un avertissement, cliquez "Informations complémentaires" puis "Exécuter quand même"
  • Le launcher se lance et affiche l'écran de connexion

3 Se connecter

Team Launcher supporte deux modes de connexion :

  • Compte Microsoft (officiel) — connexion sécurisée, authentification via le site officiel de Microsoft
  • Mode hors-ligne — pour jouer seul, sans connexion internet
Astuce : La connexion Microsoft est recommandée. Elle permet d'accéder aux serveurs en ligne et d'utiliser vos skins.

4 Gérer les instances

Une instance = une configuration Minecraft séparée (version, mods, configs). Vous pouvez en créer autant que vous voulez.

  • Cliquez sur "Nouvelle instance" pour en créer une
  • Choisissez la version de Minecraft (1.8, 1.12, 1.20, etc.)
  • Choisissez le loader (Vanilla, Forge, Fabric, Quilt)
  • Donnez un nom à votre instance

5 Installer des mods

Le launcher intègre une recherche de mods via CurseForge et Modrinth.

  • Allez dans l'onglet "Mods" de votre instance
  • Recherchez le mod que vous voulez
  • Cliquez "Installer" — le mod et ses dépendances sont téléchargés automatiquement
  • Vous pouvez aussi déposer des .jar manuellement dans le dossier mods

6 Configurer les serveurs

Team Launcher inclut un gestionnaire de serveurs avec ping en temps réel.

  • Ajoutez des serveurs avec leur adresse IP
  • Le ping se met à jour automatiquement
  • Mettez des serveurs en favoris pour les retrouver vite
  • Tunnel Internet intégré via playit.gg — créez votre propre serveur sans ouvrir de ports

7 Optimiser les performances

Le launcher vous aide à configurer Minecraft pour qu'il tourne bien sur votre PC.

  • RAM : choisissez combien de mémoire Minecraft peut utiliser
  • Arguments JVM : le launcher génère automatiquement les meilleurs paramètres
  • Profils de perf : économie, standard, ou max performances

8 Gérer Java

Pas besoin d'installer Java vous-même. Le launcher :

  • Détecte les versions de Java installées
  • Télécharge automatiquement la bonne version pour la version de Minecraft choisie
  • Gère les versions 8, 17 et 21 selon les besoins

9 Comprendre les crashs

Quand Minecraft crash, le launcher ne vous montre pas un mur de texte incompréhensible. Il explique en français ce qui s'est passé et propose des solutions.

  • Cause du crash identifiée
  • Solution proposée en clair
  • Lien vers la page d'aide si besoin

Aqua Launcher — Le futur

Aqua Launcher est le deuxième projet de Team Group. Ce sera un launcher multigaming qui rassemble tous vos jeux au même endroit.

1 Ce qui est prévu

  • Bibliothèque unifiée — tous vos jeux dans une seule interface
  • Store intégré — découvrez et installez des jeux sans quitter le launcher
  • Stats de jeu — heures jouées, victoires, classements
  • Amis & chat — voyez qui joue à quoi, discutez en temps réel
  • Thème personnalisable — changez les couleurs comme vous voulez
  • Plugins — ajoutez des fonctionnalités via DLL sans toucher au code

2 Quand est-ce que c'est dispo ?

Aqua Launcher est en cours de développement. Pas de date de sortie annoncée. Suivez l'avancement sur le Discord ou via le GitHub.

Contribuer au projet

Team Group est open source. Vous pouvez contribuer, signaler des bugs, proposer des idées.

1 Signaler un bug

Vous avez trouvé un bug ? Merci de nous le dire.

  • Ouvrez une issue sur GitHub
  • Ou envoyez un mail à teamluncher@gmail.com

Précisez toujours :

  • Ce que vous étiez en train de faire
  • Le message d'erreur (copiez-le en entier)
  • Les étapes pour reproduire le problème
  • Votre version du launcher et votre version de Windows

2 Proposer une idée

Une feature qui manque ? Un truc qui pourrait être mieux ?

  • Ouvrez une issue "Enhancement" sur GitHub
  • Décrivez ce que vous voudriez et pourquoi

3 Contribuer au code

Vous êtes dev et vous voulez aider ?

  • Fork le repo GitHub
  • Créez une branche pour votre feature
  • Faites vos modifs
  • Ouvrez une Pull Request
Techno : C# / .NET 8 / WinForms. Le projet utilise LLVM pour la compilation ahead-of-time. Pas de Electron, pas de Node.js.
